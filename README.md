# BJJ Card Game 🥋

A strategic turn-based card game built with **React**, inspired by the rules and positions of Brazilian Jiu-Jitsu (BJJ). 

This project focuses on complex client-side state management, custom game-engine logic, and responsive mobile-first UI design.
## 🚀 Quick Links
* **Play Online**: https://bgg-cards-game.vercel.app/

## ✨Game Logic
* **Turn-Based Game Engine**: Implements authentic BJJ positional progression (Standing, Guard, Mount, Side Control, Escapes, and Sweeps).
* **AI Opponent**: Built-in computer player logic that calculates valid moves and responds dynamically to the player's actions.
* **Scramble Mechanic**: A custom action mechanism allowing players to shuffle their hand (with usage limits) while preserving the game turn flow.
* **Responsive Mobile-First Design**: Tailored CSS layout ensuring seamless playability across both desktop and mobile devices.

## 🛠️ Tech Stack
* **Frontend**: React, JavaScript (ES6+), CSS3
* **State & Logic**: Custom React Hooks and modular game engine architecture
* **Audio**: Integrated background audio toggle with Web Audio support
